📋 Sao Chép Dữ Liệu Dán Vào Google Sheets
Cách cập nhật ngược lại Google Sheets trong 3 giây:
  1. Bấm nút "📋 Sao Chép Toàn Bộ Bảng" bên dưới.
  2. Mở tab Google Sheet của bạn.
  3. Chọn ô A1 và nhấn Ctrl + V. Toàn bộ các cột và dòng sẽ được cập nhật chuẩn xác!
⚙️ Cấu Hình Đồng Bộ Dữ Liệu Google Sheets
🟢 Chiều Google Sheets ➔ Web:
Hoàn toàn Tự Động 100%. Mỗi khi bạn thêm link Báo mới hay sửa trạng thái trên Google Sheet, khi vào web hoặc chuyển lại tab này, dữ liệu sẽ tự động nạp mới và tự động ghép Báo mới thành Content ngay lập tức!
🚀 Chiều Web ➔ Google Sheets:
• Cách 1 (Nhanh nhất): Bấm nút 📋 Đẩy Vào Sheet (1-Click) ở thanh tiêu đề, sau đó sang tab Google Sheets bấm Ctrl + V vào ô A1.
• Cách 2 (Tự động ngầm): Dán link Google Apps Script Webhook vào ô bên dưới để web tự động cập nhật Sheet không cần bấm phím nào!
📝 Hướng dẫn 30 giây tạo Apps Script Webhook (Nếu muốn dùng Cách 2)
1. Mở file Google Sheet của bạn ➔ Chọn menu Tiện ích mở rộng (Extensions) ➔ Apps Script.
2. Xóa hết code cũ, dán đoạn code bên dưới vào và bấm biểu tượng Lưu 💾:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (data.rows && data.rows.length > 0) {
      sheet.getRange(1, 1, data.rows.length, data.rows[0].length).setValues(data.rows);
      return ContentService.createTextOutput(JSON.stringify({ok: true, count: data.rows.length})).setMimeType(ContentService.MimeType.JSON);
    }
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ok: false, error: err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}
3. Bấm nút Triển khai (Deploy) màu xanh góc phải ➔ Tùy chọn triển khai mới (New deployment).
4. Chọn loại: Ứng dụng web (Web app). Ở mục "Ai có quyền truy cập", chọn: Bất kỳ ai (Anyone) ➔ Bấm Triển khai.
5. Sao chép link Web App (kết thúc bằng /exec) dán vào ô bên trên và bấm Lưu Cấu Hình!
